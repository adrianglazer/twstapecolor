# v0.3.24 — Automatic TWS discovery and quote-capture fix

Adds automatic discovery of renamed TWS market-record, instrument, book and row
accessors, top-record fields, and feed-hook method names. Discovery inspects
bytecode without calling candidates, caches results by class identity, and
rejects ambiguous matches with diagnostics in `status`.

Fixes the pre-release v0.3.23 regression that left rows neutral: the resolver now
distinguishes the primary top record from a wrapper that inherits its book getter.
Readable trades remain neutral if quote discovery fails.

Includes updated launchers, documentation, regression tests, an installed-archive
and reflection checker, and the bundled Java agent. Retains the inspected
TWS 10.51–10.53 access paths. This is bounded rename tolerance; target classes,
feed signatures and semantic price/bid/ask mappings remain explicit.

Validation: 19 Java test programs (including 22 resolver checks), six Python tests,
and archive/reflection checks for TWS 10.51, 10.52 and 10.53 passed. Live TWS 10.53.1a
reported zero resolver failures and data errors, with green/red paint counters
advancing. A saved snapshot of 49 quote events and 77 trades had zero direction
or preceding-quote mismatches and no missing or duplicate events. Independent
pixel/restoration audits were not repeated; Windows operation remains unverified.

**Upgrade:** restart TWS before loading this version to clear any older agent and
cached resolutions. Requires JDK 21+. Run the versioned JAR, or use `./build`
followed by `./twstapecolor start`.

Release assets: `twstapecolor-v0.3.24.jar` and `SHA256SUMS` from `dist/`.
